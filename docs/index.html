1. Installation

  1. In WordPress go to Plugins → Add New → Upload Plugin, choose dev3-ai-form-builder.zip and activate it.
  2. A new menu DEV3 AI Forms appears. Open it and click New form.
  3. Pick a template, a blank form, or Describe a form (needs a Gemini key).
  4. Embed the form with the DEV3 AI Form block or the shortcode shown under Embed.

No licence key or activation is needed. Updates are delivered as new zips through CodeCanyon.

2. Google Gemini API key

  1. Open Google AI Studio → API keys and create a key.
  2. In WordPress open DEV3 AI Forms → API Config, paste the key and save. It is encrypted (AES-256-GCM) and never sent to browsers.
  3. Optional: set a monthly budget (USD). AI pauses when it is reached; forms keep working.
  4. Alternatively define define( 'DEV3FB_GEMINI_API_KEY', '…' ); in wp-config.php.

Default models: gemini-2.5-flash (fast tasks) and gemini-2.5-pro. You can pick other models from the live list. The storefront switch turns off visitor-facing AI (spam shield, paste-to-fill) without touching admin AI.

3. The builder

  • Build: drag fields from the list (or click them) into the form; drag to reorder or between steps; use the arrows for keyboard/touch. Click a field to edit it on the right (on phones it opens as a panel).
  • Steps: "Make it multi-step" adds a step; each step has a title, description and its own logic.
  • Settings: button labels, progress (bar, step names, none), save-and-continue, open/close dates, entry limit, login-only, store entries, intro text, accent colour, CSS class.
  • Field settings: label, placeholder, help, required, width (full/half/third, stacked on phones), default value with merge tags, options with values/prices/images, min/max/step, file types and size, field ID (renaming updates logic, formulas and merge tags), autofill role, CSS class.
  • Press Ctrl/Cmd+S to save. Unsaved changes are protected when you leave the page.

5. Conditional logic & calculations

Every field, step, confirmation, notification and webhook can be shown/used when all or any rules match. Operators: is, is not, contains, does not contain, starts with, ends with, greater/less than, at least/at most, is empty, is filled in. A field can only depend on earlier fields. Hidden fields are not validated and their values are discarded on the server.

Calculation formulas use field IDs in braces:

round({area} * {quality}, 2)
if({rush} == 1, {_subtotal} * 0.2, 0)
max(0, {budget} - {discount})

Functions: min, max, round(x, decimals), floor, ceil, abs, sqrt, pow, if(condition, a, b); comparisons return 1 or 0. Choice options use their price or numeric value; toggles are 1/0. {_subtotal} is the sum of products × quantities and custom amounts. The Order total field adds products, custom amounts and calculations marked "add to total". The browser shows live results; the server always recalculates.

6. Emails & confirmations

Notifications support conditional logic, Reply-To, Cc, Bcc, attachments and merge tags: {field:ID}, {all_fields}, {form_title}, {entry_id}, {entry_url}, {payment_total}, {site_name}, {admin_email}, {date}, {page_url}. Set the From name/address in Settings → General. Confirmations show a message, open a page or redirect to a URL (merge tags are URL-encoded). The first matching confirmation wins.

7. Entries

Inbox, Unread, Starred, Awaiting payment, Spam and Trash; search across all answers; bulk mark read/star/spam/trash/delete/analyze; CSV export (UTF-8, Excel-safe, formula injection neutralised). The entry panel shows answers, files, payment, DEV3 AI insights, an AI reply composer, private notes, an activity log (emails, integrations, webhooks, payments) and buttons to resend. Retention can delete old entries automatically.

Google Sheets Apps Script

In your sheet open Extensions → Apps Script, paste this, then Deploy → New deployment → Web app (execute as you, access: anyone) and copy the URL.

function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName(data.sheet) || ss.insertSheet(data.sheet);
  var keys = ['Entry ID', 'Submitted'].concat(Object.keys(data.values));
  if (sheet.getLastRow() === 0) sheet.appendRow(keys);
  var header = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0];
  var row = header.map(function (h) {
    return h === 'Entry ID' ? data.entry_id : h === 'Submitted' ? data.submitted_at : (data.values[h] || '');
  });
  sheet.appendRow(row);
  return ContentService.createTextOutput('ok');
}

9. Payments

  1. Add a Stripe secret key (sk_test_… to test) and/or PayPal client ID + secret (sandbox toggle) in Settings → Payments.
  2. In the form's Payments tab turn payments on, pick the currency and providers.
  3. Add Product/Quantity/Custom amount/Calculation fields and an Order total.

After submitting, visitors go to Stripe Checkout or PayPal. The entry waits as "Awaiting payment"; when the payment is confirmed (return page, or Stripe webhook /wp-json/dev3fb/v1/payments/stripe with the checkout.session.completed event) it moves to the inbox and notifications are sent. Zero-decimal currencies (JPY, KRW…) are handled.

10. Spam protection & paste-to-fill

  • Without AI: hidden honeypot (bots get a fake "thank you"), minimum fill time via a signed token, submissions per minute per visitor.
  • DEV3 AI Spam Shield (per form): threshold, action (keep in Spam folder, block with a message, or deliver flagged), abusive-message blocking. Site limits: checks per minute/day, fail-open or fail-closed, skip for logged-in users. Marking a log row "Not spam" trusts that sender and restores the entry.
  • DEV3 AI Paste-to-fill (per form): visitors paste a signature or message; only empty fields are filled and they can undo.

11. DEV3 AI features

Describe your form

Forms → Describe a form. Type one sentence, choose steps and language. DEV3 AI returns fields, options (with prices), steps, logic and formulas. The draft is validated and repaired (unknown types, logic pointing to later fields, invalid formulas) and every repair is listed. Nothing is saved until you click Use this form; it is created as a draft.

Entry intelligence

Summary, sentiment, intent, category, urgency, language, tags and a 0–100 lead score. Analyze one entry, selected entries, all new entries (background job), or turn on automatic analysis in Settings. Without AI a rule-based score is used.

AI auto-replies

Entry → Reply: choose a tone and add facts (prices, dates). DEV3 AI drafts the reply in the sender's language; you edit it and click Send reply. Nothing is sent automatically.

Conversion advice

Form → Insights shows views, starts, submissions, steps reached and the field where visitors give up (anonymous, no answers stored), plus rule-based quick wins. "Get advice with DEV3 AI" explains the drop-off and suggests fixes; each fix is previewed as a draft and applied only when you accept it (then save the form).

Smart translation

Form → Translate: pick a language. Labels, help texts, options, buttons, confirmations and validation messages are translated; merge tags are protected. Review/edit, accept, save. Visitors see the translation automatically (site locale, WPML or Polylang) or with lang="de" on the shortcode/block.

12. Embedding

  • Block editor: add the DEV3 AI Form block and pick a form (and language).
  • Shortcode: [dev3fb_form id="12"] or [dev3fb_form id="12" lang="fr"] in Elementor, WPBakery, Divi, widgets or the classic editor.
  • PHP: <?php echo do_shortcode( '[dev3fb_form id="12"]' ); ?>
  • Forms loaded later by JavaScript (popups): call window.dev3fbInit().
  • Theme styling: forms inherit fonts and colours. Override CSS variables on .dev3fb: --dev3fb-accent, --dev3fb-radius, --dev3fb-field-bg, --dev3fb-border, --dev3fb-error.

14. Privacy

  • The API key and integration/payment secrets are encrypted and never sent to the browser.
  • Spam checks and insights send only text answers to Google Gemini; emails are reduced to their domain; phone numbers, passwords, files and signatures are never sent. Optional PII masking (API Config).
  • IP addresses are not stored unless you enable it. Analytics use a random per-visit id, no cookies and no answers.
  • Entries are included in WordPress's personal data export/erase tools. A privacy policy snippet naming Google Gemini is added under Settings → Privacy.
  • Uninstalling removes everything only when "Delete all data when the plugin is uninstalled" is on.

15. FAQ

The AI buttons are disabled. Add a Gemini key in API Config and check that AI is on and the monthly budget is not reached.

Emails do not arrive. Use an SMTP plugin and set a From address on your domain. The entry's activity log shows each send attempt.

Payments stay "Awaiting payment". Add the Stripe webhook (event checkout.session.completed) and signing secret so payments confirm even when visitors close the tab.

Does it slow my site? The front-end script is about 8 KB gzipped and loads only on pages with a form; no AI calls happen on page load.

Can I move forms between sites? Yes: Embed → Download JSON, then New form → Import JSON.
